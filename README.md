# Clara Asia 2027

Interactive route and timeline for Clara's Asia trip, planned for February-May 2027.

## Source of truth
Clara's **ASIEN** itinerary document is the source of truth for the dated route. The default map view preserves the dates and stated durations in that document. A second view contains possible route changes that are explicitly marked as **not yet confirmed**.

## Updating the site
When Clara changes the itinerary document, update the mapped stops/dates/notes in `index.html`, commit to `main`, and the linked Vercel project should redeploy automatically.

## Privacy
The site is shareable by URL, but includes `noindex,nofollow` metadata and a `robots.txt` disallow rule to discourage search indexing.
